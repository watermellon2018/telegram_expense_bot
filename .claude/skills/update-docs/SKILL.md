# Update Docs

Синхронизация документации с изменениями в коде. **Правь точечно** — только то, что реально устарело из-за изменения. **Не переписывай README или другие документы целиком** без явной просьбы; не трогай разделы, которых изменение не касается.

## Процедура

1. **Определи, что изменилось.** Посмотри `git diff` / суть задачи. Составь список затронутого: новая команда, новая env-переменная, изменение поведения, новая миграция, изменение деплоя.

2. **Найди только релевантные документы** и обнови минимально:
   - **README.md** — пользовательское описание, список бот-команд, общая инструкция. Обновляй только изменённые пункты.
   - **docs/ARCHITECTURE_RU.md** — если изменилась структура слоёв, добавлен модуль, изменился поток данных или появился новый паттерн.
   - **Команды** — `TESTING.md` / `SETUP_LOCAL.md`, если поменялись команды запуска/тестов/настройки.
   - **Env example** — если добавлена/удалена переменная окружения: задокументируй её в README/SETUP_LOCAL и в `.env`-секции `deploy.yml` (отдельного `.env.example` в репозитории сейчас нет — если нужен, согласуй создание).
   - **Бот-команды** — список `/команд` и кнопок меню (источник — `config.py`), если добавлена/переименована команда или кнопка.
   - **Deployment** — если изменился `Dockerfile`/`docker-compose.yml`/workflow или процесс выката.
   - **Пользовательское поведение** — если изменился UX (новые сообщения, изменённая логика ответов).
   - **Миграционные инструкции** — если добавлена `.sql` миграция: задокументируй, как её применить (вручную через `psql`/asyncpg), в SETUP_LOCAL/README.
   - **[CLAUDE.md](../../../CLAUDE.md)** — обнови ТОЛЬКО если изменилось постоянное правило/структура (новый слой, смена инструментария). Не дублируй сюда описание конкретной задачи.

3. **Согласованность.** Проверь, что обновлённые факты не противоречат друг другу между документами (например, версия Python, набор команд).

4. **Не выдумывай.** Документируй только то, что подтверждается кодом. Если поведение неоднозначно — отметь это, а не описывай предположение как факт.

## Вывод
Краткий список: какие файлы и какие разделы обновлены и почему. Нетронутые документы не упоминай.
